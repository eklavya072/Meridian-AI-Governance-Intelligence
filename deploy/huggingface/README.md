# Meridian — AI policy gap analysis

Evaluates a national AI policy against 43 international reference
frameworks across eight governance dimensions, with every quoted passage
checked against its source.

Eight finished country analyses are included as read-only examples (EU,
Japan, India, Kenya, Egypt, United Kingdom, China, Rwanda). Create a
workspace of your own to upload a policy PDF and run the full pipeline, ask
the Rapporteur about any finding, or talk to the AI Auditor.

This Space is a demo: its disk is not persistent, so your workspaces are
cleared whenever it restarts.

Source code: see the GitHub repository linked from the profile.
